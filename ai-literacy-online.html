Concept 1: Generative AI and oral language

Try a prompt on your own speaking and listening activity

Prior to the live session, use an AI tool of your choice to input the following prompt:

You can use any AI tool you like.

“Suggest an improvement for the following speaking and listening activity: <insert your summary here>.”

Do not put student names or other identifying details into an AI tool.

Concept 2: Generative AI and reading

Trial a prompt for a reading text

Select a short reading text you would use with your students. Identify one reading focus area you would like students to improve, and trial a prompt that might help AI develop a teaching activity to use with the text.

For example

If you would like students to develop their vocabulary skills, enter the following prompt: “Design a teaching activity to help students identify key vocabulary in this text.”

Concept 3: Generative AI and writing

Ask for a model response

Identify a writing task you would ask your students to complete. Ask an AI tool of your choice to create a model response for this task.

An example prompt might be

“Students are asked to write a short description of a garden. Write a model response using descriptive language at an appropriate level for a 10 year old Indonesian student.”

Before the live session

  • One example that focuses on listening and/or speaking
  • One example that focuses on reading
  • One example that focuses on writing
